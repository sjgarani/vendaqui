# VendAqui — Contexto do Projeto para IA

## Sobre o Projeto

VendAqui é uma plataforma de e-commerce/vendas. Este arquivo serve como
contexto rápido para ferramentas de IA entenderem o projeto.

## Convenções

- Commits: Conventional Commits obrigatoriamente em inglês (ex: `feat: add initial project structure`), com sufixo `[ai-assisted]` quando aplicável
- Branches: feat/, fix/, docs/, refactor/, test/
- Código: seguir padrões definidos em docs/ARCHITECTURE.md

## Documentação Relevante

- Arquitetura: docs/ARCHITECTURE.md
- Diretrizes de IA: docs/AI_GUIDELINES.md
- Engenharia de Prompts: docs/PROMPT_ENGINEERING.md
- Revisão de Código IA: docs/AI_CODE_REVIEW.md

## Regras para IA

1. Sempre seguir os padrões de arquitetura definidos
2. Nunca hardcodar credenciais ou segredos
3. Sempre incluir tratamento de erros
4. Sempre adicionar tipagem (quando a linguagem suportar)
5. Gerar testes para toda funcionalidade nova
6. Manter funções pequenas e com responsabilidade única
7. Usar nomes descritivos em português ou inglês (manter consistência)
